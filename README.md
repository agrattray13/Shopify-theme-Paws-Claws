# Artesian Steps — Premium Shopify Theme

Artesian Steps is an upscale, premium, upper-class Shopify theme meticulously designed for high-end Men's Wear boutiques, bespoke tailoring services, and luxury accessory brands. Offering an exquisite, editorial aesthetic, it is engineered for absolute sophistication, exceptional brand storytelling, and high-performance commerce.

## Design Highlights & Aesthetic

* **Sartorial Editorial Layout:** Designed like a luxury fashion editorial, featuring spacious layouts, clean lines, and an atmosphere of refined elegance.
* **Curated Premium Palette:**
  * **Branding Accent:** Brushed Brass / Antique Gold (`#8D7257`)
  * **Default Background:** Luxury Alabaster Ivory (`#FAF8F5`)
  * **Contrast Dark Theme:** Elegant Midnight Navy (`#111625`) & Obsidian Black (`#121212`)
  * **Typography Contrast:** Deep Obsidian Charcoal (`#1A1A1A` / `#2A2520`)
* **Sophisticated Typography:** Classic, high-end serif headlines (Playfair Display) paired with clean, geometric, elegant sans-serif body text (Assistant) for ultimate legibility and high-fashion style.
* **Immersive Home Page:** Featuring an editorial hero banner, a heritage storytelling narrative section, curated signature collections, detailed craftsmanship highlights, brand pillar reviews, and an elegant "Club Privé" private-member newsletter signup.

## Getting Started

1. **Customize Sections:** Use the Theme Editor to select and arrange premium sections (like `rich-text` heritage narrative, `image-with-text` details, or `multicolumn` pillars).
2. **Setup Navigation & Menus:** Set up elegant menu links for bespoke suits, tailored outerwear, and heritage accessories.
3. **Configure Brand Assets:** Upload high-resolution, professional menswear imagery, and configure your logo (recommended display width: 140px - 160px).

## Developer Tools & Validation

We recommend using [Theme Check](https://github.com/shopify/theme-check) to validate and lint the theme files. Run the following command from the terminal:

```bash
shopify theme check
```
